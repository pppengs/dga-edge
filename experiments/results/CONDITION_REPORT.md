# IEEE C57.104-2019 condition grading vs. published labels

Generated by `experiments/run_condition.py`.

## Question

The ratio methods ask *which* fault it is. Before that, an online
monitor has to answer *whether anything is wrong*. IEEE C57.104-2019
Table 1 grades every sample into Condition 1-4 from absolute
concentrations and TDCG. This experiment scores that grading as a
binary alarm (condition >= 2) against the datasets' own labels.

## Alarm performance

| dataset | n | normal labelled | accuracy% | recall(fault)% | specificity% | precision% | false alarm% |
|---|---|---|---|---|---|---|---|
| alan456_589 | 589 | 0 | 95.8 | 95.8 | n/a | 100.0 | n/a |
| cliango_202 | 202 | 34 | 94.1 | 95.2 | 88.2 | 97.6 | 11.8 |

`specificity` is meaningful only where the dataset actually contains
labelled healthy units; a dataset with no Normal class cannot produce
false alarms by construction, so its specificity is undefined.

## False alarm rate of the ratio methods on healthy units

Scored only on samples labelled Normal. A method that cannot
emit a "healthy" verdict is forced to alarm here, which is
invisible in per-class recall.

| dataset | method | normal units | flagged as fault | false alarm% |
|---|---|---|---|---|
| cliango_202 | iec_three_ratio | 34 | 11 | 32.4 |
| cliango_202 | iec_ratio | 34 | 4 | 11.8 |
| cliango_202 | rogers_ratio | 34 | 10 | 29.4 |
| cliango_202 | duval_triangle1 | 34 | 34 | 100.0 |

Duval Triangle has no normal zone at all, so it alarms on
essentially every healthy unit. This is the concrete case for
grading on absolute concentrations first: it decides *whether*
to alarm far more reliably than any ratio method decides
*which* fault it is.

## Caveats

- Condition grading is threshold-based and knows nothing about gas ratios;
  a high-reading but benign unit and an actively faulting one can
  land in the same condition band.
- TDCG can never raise the condition under Table 1: for every level k,
  the sum of the per-gas Ck limits is below the Ck TDCG limit
  (686 < 720, 1879 < 1920, 4585 < 4630). This is asserted by
  `tests/test_condition.py::test_tdcg_never_raises_the_condition`.
- Labels are the datasets' own annotations, not independent inspection.
